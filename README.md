# Guide des couleurs

Atlas de vingt couleurs lues à travers cinq aires culturelles : significations, valeurs véhiculées, pièges à l'international, contraste d'accessibilité et sources.

Site statique (un seul fichier, `index.html`), prévu pour GitHub Pages : https://alexooosss.github.io/guide-des-couleurs/

Les images de référence sont chargées depuis Wikimedia Commons et Pexels ; leurs auteurs et licences sont indiqués sous chaque image.
